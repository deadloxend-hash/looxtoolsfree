PDF Splitter

Share the pages that matter, with less to search through.

Sometimes a whole document is more than the reader needs. Extract a chapter, a form or a focused set of references into a separate file. A smaller selection makes the purpose of the document easier to understand.

LOOX TOOLS

Count pages as the viewer does

Enter individual pages and ranges such as 1-3,7. The first page in the file is page 1, even if the printed page number on the paper says something different. Review the output before sharing and remember that extracting a page does not redact private information on that page.

  • Extract specific pages without re-creating the document.
  • Use individual page numbers or ranges.
  • Create a new PDF with only the selected pages.

Double-check page numbering before extraction. PDF viewers normally number the first page as page 1, even when the printed page number inside the document is different.

LOCAL / NETWORK

Your files deserve a clear explanation

PDF operations run in your browser with PDF-Lib loaded from jsDelivr. The selected PDF is not uploaded to LOOX by this splitter workflow. Protect exported documents if they contain private information.

A thoughtful final check

Review identifying details, confidential information and the final file before sharing. Local processing does not automatically remove metadata or guarantee anonymity. AI-generated or heavily edited content may need clear labeling.

LOOX HELP

Questions, answered

How do I select pages 1, 2, 3 and 7?

Enter 1-3,7 in the page range field.

Can I extract a single page?

Yes. Enter that page number, such as 5.

Is my PDF uploaded?

No. Splitting is performed in your browser; the PDF library is downloaded from a CDN.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
