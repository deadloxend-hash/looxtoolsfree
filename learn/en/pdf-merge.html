LOOX FIELD NOTES

PDF Merger

Bring separate documents into one clear reading order.

A proposal, a set of notes or a collection of receipts is easier to use when the pages belong together. Decide on the reading order before selecting files, so the finished document feels intentional from its first page.

LOOX TOOLS

Check the order before sharing

Files are combined in the selected order. Use clear filenames to make that order easier to recognize, and open the downloaded PDF to check the transitions between documents. Protected or unusually large PDFs may need another workflow. Keep the source documents available.

  • Combine separate PDF documents.
  • Keep pages together in one file.
  • Process the selected files in your browser.

Name and select files in the intended reading order before merging. If a document contains private information, use a trusted device and keep the exported PDF secure.

LOCAL / NETWORK

Your files deserve a clear explanation

PDF operations are handled in your browser using the PDF-Lib library, which the page loads from jsDelivr. Your selected PDF documents are not uploaded to LOOX by this merge workflow.

A thoughtful final check

Review identifying details, confidential information and the final file before sharing. Local processing does not automatically remove metadata or guarantee anonymity. AI-generated or heavily edited content may need clear labeling.

LOOX HELP

Questions, answered

How many PDFs can I merge?

Select at least two files. Practical limits depend on file sizes and available browser memory.

Can I change the page order?

Select files in the order you want them to appear in the output.

Are my PDFs uploaded?

The merge runs in your browser. The library is loaded from a CDN, but the selected PDFs are not sent to LOOX.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
