LOOX FIELD NOTES

Images to PDF

Turn a collection of images into a document people can follow.

A visual collection becomes easier to read when every image has its own page. Gather scans, reference photos or a simple visual portfolio into a file that keeps the order intact.

How to use Images to PDF ↓
Illustrated workflow

How to use Images to PDF

01

Choose your images

Select one or more JPG or PNG images from your device.

02

Check the selection

Images are added in the selected file order. Make sure that order is correct.

03

Create the PDF

The browser creates one PDF page for each selected image.

04

Download your document

Save the PDF and open it to check page size and image orientation.

LOOX TOOLS

Prepare the pictures first

Choose JPG or PNG images in their intended order. Correct orientation and remove unnecessary borders before conversion. Large source images can create a large PDF; resize copies first when full resolution is not needed. Keep the original images for future edits.

  • Combine separate images into one document.
  • Create a page for each selected image.
  • Export a standard PDF file.

Large, high-resolution images can create a large PDF. Rotate photos correctly before combining them and keep the original images as a backup.

LOCAL / NETWORK

Your files deserve a clear explanation

The PDF is created locally in your browser using PDF-Lib loaded from jsDelivr. Your selected images are not uploaded to LOOX by this tool.

A thoughtful final check

Review identifying details, confidential information and the final file before sharing. Local processing does not automatically remove metadata or guarantee anonymity. AI-generated or heavily edited content may need clear labeling.

LOOX HELP

Questions, answered

Which image formats are supported?

The current tool supports JPG/JPEG and PNG.

Will each image get its own page?

Yes. The tool creates one PDF page for each selected image.

Are images uploaded?

No. Image embedding and PDF creation happen locally in your browser.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
