# LOOX Utilities 2.0 — release report

26 November 2026. Frontend: `deadloxend-hash/looxtoolsfree`. Page: https://deadloxend-hash.github.io/looxtoolsfree/index.html . Theme: LOOX Obsidian Blue. MediaGrab, backend services, account/security logic and payment configuration were not changed.

## Delivered experience

Replaced the oversized promotional stack, overlapping homepage styles, duplicate AI slideshow and artwork-heavy utility cards with a compact discovery dashboard. Search is visible immediately, featured Studios open real workspaces, and the actual utility grid follows compact category and collection controls. Informational content, directories, privacy guidance and FAQs remain below discovery.

The audited catalog contains **122 unique existing tool/workspace destinations**: **114 available workspaces/utilities and 8 Coming Soon previews**. This describes the directory state, not a guarantee that every external AI provider is online. All 55 tools listed by the former homepage are retained. The existing 119-entry source catalog supplied additional already-present tools; the AI Image, AI Assistant and AI Video product destinations complete the directory. No invented processing tools or popularity figures were added.

### Discovery and personalization

- Instant token-based search across names, descriptions, categories and keywords, with accent normalization, task synonyms and flexible word order. “remove background”, “background remove” and “cut out subject” find the background remover; “make photo smaller” finds image compression.
- Ten real category filters: AI Tools, Photo Editing, Video Editing, Image Utilities, Video Utilities, Audio Utilities, PDF & Documents, File Conversion, Developer Tools and Everyday Utilities. Tools can belong to more than one relevant category.
- All utilities, Favorites, Recently used, Popular picks, For you and Recently updated collections. Popular picks are explicitly editorial starting points, not measured rankings. For you uses categories from local recent tools, with an editorial fallback. Only the genuinely updated Photo/Video Studio pages receive the 26 November update date.
- Reuses the existing `loox-favorites-v1` and `loox-recent-v1` storage keys, so recognized saved tools survive the redesign. Individual favorites and recent entries are removable. Favorites support the entire directory. Recent searches have individual removal and clear-history controls.
- Local storage is validated against known URLs, bounded and exception-safe. If storage fails, choices continue for the current visit with a visible explanation. No files, generations or document contents are stored by this dashboard. Favorites/history are device-local, not account-synced.
- Keyboard: `/` focuses dashboard search; Arrow Down focuses a matching result; grid arrow keys/Home/End navigate results; Escape returns to search. Recent searches have keyboard controls. The dashboard shortcut intercepts the shared shortcut only for `/` on this page; shared header search/Ctrl+K remain available.
- URL query/category/collection state, clear/reset controls, empty states, live result counts and show-more pagination. Initial layout displays 24 available cards; all static links are present in the HTML for discovery without JavaScript.

### Visual and responsive design

- Compact hero with restrained typography, immediate search and direct background-removal/compression/PDF shortcuts. The original lightweight workspace illustration is a 1 KB SVG; there is no large hero photograph, font download or rotating slideshow.
- Featured Photo Studio, Video Studio, AI Image Generator, AI Assistant and AI Video Generator (Coming Soon). Original CSS/SVG workspace illustrations. On mobile the featured workspaces form a horizontal strip, leaving room for actual utilities.
- Consistent cards with original SVG icons, short descriptions, full-card anchor targets, separate favorite controls, clear focus/hover states, and an explicit processing/preview label. Coming Soon previews have their own section.
- Two-column small-screen tool grid; three/four/five columns as space allows. Native scrollable category/collection controls and workspaces do not create horizontal page scrolling. Touch targets and bottom safe-area spacing are included.
- Removed the visible collapsed blue edge grip **only on the Utilities homepage** with a narrowly scoped override. The shared header, account controls, logo, credits, Upgrade link and mobile apps menu remain owned by the existing navigation module.
- Shared light/dark, custom background/accent, reduced-motion and font-scale preferences are supported. No page-specific appearance dropdown duplicates the account settings.

## Performance and implementation

`platform/utilities-catalog.json` is the editable source of truth. `scripts/build-utilities.cjs` generates crawlable cards and accurate structured data into `index.html`. The browser reads those static cards; it does not fetch a second catalog, load an AI slideshow or build a large image gallery. Search reuses the existing DOM nodes and coalesces work through a microtask, avoiding background animation-frame throttling.

Measured DOM-filter/update time across eight queries was **at most 1.00 ms in the final Chrome test run** (other runs ranged up to 2.00 ms). This is the filtering/update measurement on this machine, not end-to-end input latency, paint time, a mobile benchmark or a Lighthouse score.

The page now serves more than twice as many tool links statically. Its raw HTML is larger, but local gzip comparison was about **20.6 KB versus 24.8 KB** for the former homepage, before the final schema exclusion made it smaller still. This is a reproducible compression comparison, not a production network trace. The new page removes the old homepage enhancement/landing styles, inline legacy theme/catalog renderer and dashboard slideshow module. Shared navigation/account resources are preserved. New assets have versioned URLs; GitHub Pages controls HTTP caching. There is no service worker or private-response cache.

## SEO and safety

- Descriptive title/description, one H1, semantic section headings, descriptive links and original artwork alt text.
- Preserved the established canonical root `https://deadloxend-hash.github.io/looxtoolsfree/`, matching the sitemap; index.html and filter URLs canonicalize to the root.
- CollectionPage/ItemList JSON-LD lists **102 available, indexable tool destinations**. Coming Soon and pre-existing noindex pages are excluded from that list. No fabricated ratings, prices, download counts or SearchAction claims.
- Existing noindex restrictions and sitemap remain intact. Audit validated all **493 sitemap URLs** against local files and found **zero noindex URLs in the sitemap**. Every available indexable dashboard target is already covered, so a sitemap edit was unnecessary.
- Catalog URLs are same-site files/known fragments; static names/keywords are escaped by the builder. Search/history strings are inserted as text, never executable HTML. No generation jobs, paid API calls, uploads, checkout activation or security changes were introduced.

## Bugs fixed

- Promotional hero and slideshow delaying useful tool discovery, especially on phones.
- Oversized artwork on every small utility card and conflicting layers of homepage CSS.
- Missing inline universal search, phrase-only filtering and a duplicate shared/dashboard `/` shortcut collision.
- Inability to remove individual recent tools; limited discovery beyond the former 15-card page.
- Favorites/history values being trusted without validating known tool URLs; favorites above 100 could otherwise be lost on reload.
- Unwanted blue collapsed-sidebar edge indicator on the Utilities page.
- No clear distinction between available utilities and inactive cloud previews.
- Missing support for enlarged card text through the shared font-scale preference.

## Remaining practical limits

Responsive checks ran in Chrome iframe viewports, not physical phones, Safari/Firefox or simulated slow mobile networks. No Lighthouse/field Core Web Vitals score is claimed. The shared header/account libraries still determine their own startup behavior and network requirements. Utility processing engines and authenticated sessions were not exhaustively retested; this release audits dashboard discovery, destination routing and the stated interactions. Cloud processing remains dependent on backend/model availability and account requirements. Availability labels are curated catalog data and must be updated when services launch. Recently used means tools opened from this dashboard; favorites/history are not cross-device sync. Search is deterministic keyword/task matching, not a paid semantic-search service.
