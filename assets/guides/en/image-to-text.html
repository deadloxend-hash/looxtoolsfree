How to use Image to Text · OCR

01

Choose your source file

Open a supported file from your device. The original is kept separate from the exported result.

02

Adjust the tool settings

Recognize printed text locally with downloadable OCR language models. OCR runs locally after its engine and language models download. Other AI workspaces contact the configured processing endpoint only after you choose Run and consent to the upload. Availability depends on the model services enabled by the site owner. An unavailable service is shown explicitly; a standard resize or softening filter is never presented as an AI result.

Use the preview to check composition, readability and the selected dimensions. Brush and crop controls accept touch as well as mouse input.

04

Export a separate result

Use Export or the individual download links. Compare the saved file with the source and keep the original for future edits.

LOCAL / NETWORK

Your files deserve a clear explanation

Image operations run locally in your browser. Selected files are not uploaded by this module. Specialized formats, PDF, OCR and video features may download pinned third-party processing libraries or language models; the source media is still processed on this device.

A thoughtful final check

Review identifying details, confidential information and the final file before sharing. Local processing does not automatically remove metadata or guarantee anonymity. AI-generated or heavily edited content may need clear labeling.

LOOX HELP

Questions, answered

What does Image to Text · OCR do?

Recognize printed text locally with downloadable OCR language models.

Does it change my original file?

No. The workspace exports a separate result. Keep the source if you may want another version.

What should I check before using the result?

OCR runs locally after its engine and language models download. Other AI workspaces contact the configured processing endpoint only after you choose Run and consent to the upload. Availability depends on the model services enabled by the site owner. An unavailable service is shown explicitly; a standard resize or softening filter is never presented as an AI result.

Are there any practical limits?

Very large files can exceed browser memory. Specialized source formats need a supported decoder, and the saved image may not retain source metadata.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
