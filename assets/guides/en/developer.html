LOOX TOOLS

Encoding is not secrecy

Base64 and URL encoding change how text is represented, but they do not encrypt it. Use sample data when exploring a new utility. The password generator uses browser cryptographic randomness; keep generated passwords private and store them in a trusted password manager.

  • Format and validate JSON.
  • Encode or decode Base64 and URL text.
  • Count words and characters or generate random passwords.

Base64 is encoding, not encryption. URL encoding prepares text for use in URLs but does not make it secret. Treat the outputs as ordinary text unless you use a separate security mechanism.

LOCAL / NETWORK

Your files deserve a clear explanation

These helpers run locally in your browser. The password generator uses the browser’s cryptographic random-number API. Do not paste API keys, passwords or private tokens into any website unless you trust it; local browser processing does not protect against a compromised device or browser extension.

A thoughtful final check

Review identifying details, confidential information and the final file before sharing. Local processing does not automatically remove metadata or guarantee anonymity. AI-generated or heavily edited content may need clear labeling.

LOOX HELP

Questions, answered

Does Base64 protect sensitive data?

No. Base64 is reversible encoding, not encryption.

Is the password generator random?

It uses the browser crypto.getRandomValues API to generate random values. Keep generated passwords private.

Is text uploaded?

The utility actions run locally in your browser.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
