Put sideways pages back into a comfortable reading position.

One angle for the whole document

LOOX HELP

Questions, answered

Can I rotate only one page?

This tool rotates every page. Use a full PDF editor for page-by-page rotation.

What does 270° clockwise mean?

It is equivalent to turning the page 90° counter-clockwise.

Is my PDF uploaded?

No. The selected file is processed locally in your browser.

Will this replace my original file?

The tools create a separate output. Keep the original until you have checked the exported file; the site does not provide cloud project backups.

Can I publish the result?

Use source media you own or have permission to edit. Check the destination’s requirements and the rights of anyone shown before publishing.
