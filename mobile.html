LOOX Mobile

Creative tools designed for responsive mobile web workflows.

Creative tools for touch screens

LOOX Mobile is the responsive web experience available in a modern mobile browser. There is no separate installation required.

  • Touch-ready controls: Larger targets, responsive panels and direct canvas gestures support smaller screens.
  • Device-aware performance: Processing speed and maximum file size depend on available memory, browser capabilities and device hardware.
  • Heavy projects: A desktop browser is recommended for long videos, large batches and complex multi-layer compositions.
