# Image and media workspaces

Run `node scripts/build-master-tools.mjs` from the repository root after updating the registry. Pass a generated-art manifest path as the first argument only when importing new generated images. `content/image-tool-definitions.mjs` defines dedicated URLs, preset dimensions, operations, categories and editorial content. `content/image-tool-translations.mjs` supplies Spanish, French and German tool names. Existing editors are preserved.

`loox-image-workbench.mjs` mounts operation-specific controls. Local primitives are in `tools/image-core.mjs`; cancelable FFmpeg jobs are in `tools/video-utilities.mjs`. The new workspaces do not require a server for image operations, OCR, PDF rendering or video encoding. Specialized processing downloads pinned dependencies from jsDelivr: FFmpeg, heic-to (libheif), UTIF/pako, PDF.js and Tesseract. Their own open-source licenses apply; this code does not relicense third-party libraries. Ordinary canvas adjustments do not upload media.

Target compressors seek a file **at or below** the cap, reducing dimensions if encoding quality alone is insufficient. Lossless PNG recompression preserves existing chunks and recompresses concatenated IDAT data; it keeps the original if larger. DPI conversion writes PNG pHYs or JPEG JFIF density metadata and does not synthesize detail. Perspective correction is a local four-point homography. Passport output is a manual 600 × 600 / 300 DPI template, not a certification or an automatic face detector. SVG imports strip active content and external dependencies. Still-image converters use the first frame/page when the source contains multiple images.

Real AI upscaling uses the existing backend Magic Hour account when configured. Prompt-based restoration and portrait retouching use its Qwen Edit image-editor endpoint and produce model interpretations up to a 1K longest edge. Mask-enforced inpainting and generative expansion use the fixed, server-configured media AI bridge and stay unavailable until enabled. See the backend repository’s `MEDIA-AI-SETUP.md`. Cancellation stops client polling; an already submitted provider job may continue. Check AI result resumes the current job without another paid submission. No live model requests were made during implementation.

`all-image-tools.html`, `all-text-tools.html`, `all-video-tools.html`, `all-ai-tools.html` and eight permanent category pages contain static crawlable links. The More dialog uses the same catalog. The build also maintains tool guides, illustrated step assets, icons, canonical links, structured data and the sitemap. Original generated images and prompts live in `assets/tool-art/` and `content/generated-assets.json`. Guide artwork is conceptual, not measured output or application screenshots. Assets and content do not guarantee search placement, exclusivity or advertising approval.

Implementation was checked for JavaScript syntax and internal source references only. Browser interaction, codec compatibility, visual app behavior and live provider responses were deliberately left for the site owner to test.
